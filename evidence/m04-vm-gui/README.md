# Evidenze M04 vm-gui

Questa cartella riceve i report tecnici e i record umani prodotti seguendo
`teacher/M04_CLASSROOM_REHEARSAL.md`.

Stato corrente: **nessuna evidenza fisica registrata**.

Convenzione dei nomi:

```text
windows-amd64-AAAAMMGG-HHMM.json
windows-amd64-AAAAMMGG-HHMM-human.md
macos-arm64-AAAAMMGG-HHMM.json
macos-arm64-AAAAMMGG-HHMM-human.md
```

Un JSON `passed` è evidenza tecnica del solo profilo indicato. Il record umano
associato resta necessario per dichiarare osservato il percorso studente. Nessun
file in questa cartella concede automaticamente teacher sign-off o classroom GO.

Non inserire dati personali, credenziali, hostname o log non redatti.
