# Da `print` a `return`

La funzione nello starter sa già calcolare l'area del rettangolo.

Il problema è **come comunica il risultato**:

- `print(...)` mostra un valore sullo schermo;
- `return ...` restituisce un valore al punto del programma che ha chiamato la funzione.

## Obiettivo

Modifica soltanto ciò che serve affinché:

```python
risultato = area_rettangolo(3, 4)
```

metta il valore calcolato dentro `risultato`.

Non aggiungere input, messaggi o codice di prova obbligatorio nel file consegnato.

## Prima di consegnare

Prova mentalmente almeno questi casi:

- due dimensioni positive;
- una dimensione uguale a zero.

Chiediti: **la funzione mostra il valore oppure lo restituisce davvero al chiamante?**
