# Guida studente — dal `print` al file

Lo starter sa gia:

1. leggere `misure.txt` in UTF-8;
2. trasformare le righe non vuote in interi;
3. calcolare il totale.

Il problema e soltanto l'ultimo passaggio: il totale non deve essere stampato sul terminale.

Deve essere salvato in:

```text
risultato.txt
```

con encoding UTF-8 e una newline finale.

Per provare localmente usa il `misure.txt` presente nello scaffold. Durante la correzione TheBitLab puo fornire una fixture diversa: non inserire nel codice numeri attesi o percorsi assoluti del tuo PC.

Obiettivo della Controlled Change:

```text
calcolo gia corretto
→ sostituire presentazione su stdout
→ persistenza in un file testo
```
